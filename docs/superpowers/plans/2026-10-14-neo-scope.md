# neo-scope Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task. Steps use checkbox syntax.

**Goal:** Deliver a standalone floating finder with file, buffer and literal text search.
**Architecture:** One installable Elisp library owns sessions, child frames and built-in sources. Candidate plists and callback-based sources expose optional replacement points without dependencies.
**Tech Stack:** Emacs 29.1+, cl-lib, project, timers, ERT. Emacs 30+ use-package :vc for installation.
**Spec:** ../specs/2026-10-14-neo-scope-design.md

## Global Constraints

- No mandatory external Elisp package, executable or font.
- GUI first, local files only; default 90% frame size, 40:60 split.
- Implementation in the user-designated checkout; no commit or push requested.
- User explicitly requested implementation; proceed inline through verification.

## Review Focus

- Late callbacks after cancellation must not populate another session (task 2).
- Preview must not change existing buffers or execute file-local variables (task 3).
- Newlines in paths must not break candidate identity or layout (tasks 1 and 3).
- Deleting a frame and repeated opening must clean owned resources (task 3).
- Large files and inaccessible directories must report omissions without hanging (task 2).

### Task 2: Sources and lifecycle

Files: neo-scope.el, tests/neo-scope-tests.el.
Interfaces: source plist (:name :start :query-dependent :matcher :preview :action); start(query,emit) returns cancel closure. emit(event,payload) supports add/done/status/error. Generation-bound emitter rejects stale results. neo-scope-file-source(root,grep) constructs built-in source.

- [x] Write fixture tests for exclusions, literal grep, limits, cancellation and stale generation.
- [x] Run failing tests, implement bounded timer batches and source contracts, then run passing tests.
- [x] Use synchronous filesystem operations only within batches; document remaining I/O limits. No mandatory rg adapter in first version.

### Task 3: Floating UI and preview
