# 通常フレーム表示と終了処理の検証

2026-10-14、Windows / Emacs 31.1、隔離した `-Q` セッションで検証。

- ERT 33件成功（検索、プレビュー、実ffprobeを含む）。バイトコンパイル警告なし。
- `tests/neo-scope-gui.el`: 既存フレームに3ペインを表示。検索・確定、C-g、候補ペインのq、quit-windowのコマンドリマップ、各ペインのkill-bufferで全体を終了。
- 開く前の2分割、選択ウィンドウ、バッファ、point、window-startを復元。モード初期化後もバッファ終了フックが残ること、再オープン、リサイズ、フレーム削除時の後始末を確認。
- `tests/neo-scope-media-gui.el`: 画像・動画・音声の表示後、プレビューバッファを直接閉じてセッションと取得プロセスが残らないことを確認。

候補・プレビューは内部バッファで、バッファ一覧には入力用の `*neo-scope*` を表示する。子フレームは作成せず、終了時には保存したウィンドウ構成を復元する。
