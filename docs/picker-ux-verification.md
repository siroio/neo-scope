# 検索と一覧・プレビューの改善

2026-10-15、Windows / Emacs 31.1、neo-scope 0.5.0。

0.4.0の「スペースを削除して連結する」検索を、空白で区切った語を順不同で照合する方式へ変更した。自作ファジーは各語の部分列一致をANDで要求し、各語のスコアの合計と一致位置の和集合を返す。単語内のスコア・位置と同点の取得順は維持する。増分照合の比較では語の区切りを保持し、`ab` → `a b` のように一致条件が広がる編集は全件照合へ戻す。

自作grepは各語を同じ行でリテラルAND検索する。ConsultとOrderlessでは全角スペース・タブを半角スペースへ揃え、それぞれの複数語処理へ渡す。Orderlessの正規表現・dispatcherとConsultの正規表現設定は維持する。

候補表示はファイル名を先頭、ディレクトリを後方のshadow faceへ移動する。照合・確定用の文字列とパスは変更せず、一致箇所を付与してから表示を組み替えるため、ディレクトリの一致箇所も維持する。

コードプレビューは画面内の所有バッファだけを既定で簡略表示し、M-iで詳細表示へ切り替える。公開preview関数を外部で直接呼ぶ場合は従来の詳細表示を維持する。画像・動画・音声は情報表示を継続する。画面を開く際、レイアウト構築後に入力ウィンドウを明示的に選択する。

57件のERT、警告なしのバイトコンパイル、0.5.0の隔離インストールとautoload検証が成功。Evil有効の通常GUIで、開いた直後のフォーカスを変更せず `ta be` を入力しbetaの確定、取消と画面復元を確認した。

連携GUIでは逆順語でのVertico確定、Consult結果の簡略プレビューと詳細切替・入力フォーカス維持を確認。メディアGUIでは画像表示、動画・音声情報と終了時のプロセス清掃を確認した。ERTは半角・全角・連続空白・タブ、語の順序、増分検索の完全照合との一致、パス移動後の強調位置、詳細切替後の該当行を含む。

実設定全体・手動IME・他OSの描画や物理キー操作は未検証。
